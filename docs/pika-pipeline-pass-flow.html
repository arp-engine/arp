Pass / subpass relationship

In this graph, a pass is a FrameGraph pass created by graph.addPass(). A subpass is the deterministic inner recording step owned by that pass: executeRenderPass() callback, renderer recordPass()/recordShadowPass(), and the pass-kind draw-plan filter.

CsmShadow FrameGraph depth pass on CsmShadowAtlas
RenderPass subpass shadowRenderPassCallback() builds PiKaStylizedShadowRenderPassContext.
Renderer action SceneRenderer::recordShadowPass(..., StylizedShadowPassKind::Csm).
Draw-plan filter Shadow caster submeshes only; transparent blend materials are skipped.
CharacterShadow FrameGraph depth pass loading CsmShadowAtlas
RenderPass subpass Same atlas context, with LoadOp::Load after CsmShadow.
Renderer action SceneRenderer::recordShadowPass(..., StylizedShadowPassKind::Character).
Diagnostic branch Missing caster inputs keep the pass but emit explicit skipped diagnostics.
MainScene FrameGraph color + depth pass
RenderPass subpass sceneCallback() provides SceneDepth and CsmShadowAtlas.
Renderer action SceneRenderer::recordPass(..., StylizedScenePassKind::Forward).
Draw-plan subpass PiKaPassPolicy always starts with PiKaPassKind::Forward.
CustomScenePass:* Four dedicated PiKa scene passes
XRayMask subpass CustomScenePass:PiKaXRayMask records StylizedScenePassKind::XRayMask.
Outline subpass CustomScenePass:PiKaOutline records StylizedScenePassKind::Outline.
PlanarShadow subpass CustomScenePass:PiKaPlanarShadow is gated by auxiliary shadow policy.
FurShell subpass CustomScenePass:PiKaFurShell expands into fur-shell layer commands.
Postprocess passes follow the same outer/inner shape: each CustomPostprocess* pass is a FrameGraph pass, while SsaoRenderer::recordPass(), FxaaRenderer::recordPass(), or the in-place empty callback is its inner recording step.

Pass contract summary

Stage Current behavior
Frame resources SceneDepth, CsmShadowAtlas, ClusterLightList, optional GI resources, and optional CustomSceneColor are created by the composer.
Shadow atlas CsmShadow clears the D32 atlas. CharacterShadow loads the same atlas. Both use recorded render pass callbacks when caster inputs are complete.
Main scene MainScene reads the shadow atlas and light list, then records the stylized scene with StylizedScenePassKind::Forward.
PiKa auxiliary scene passes The composer injects dedicated callbacks in this order: XRayMask, Outline, PlanarShadow, FurShell. Draw commands are filtered by the pass kind and material policy.
Postprocess Anime defaults enable bloom, tone mapping, LUT, height fog, ambient occlusion, FXAA, and sharpen. Individual switches can disable each pass.
Diagnostics Missing shadow caster inputs produce explicit CsmShadow skipped and CharacterShadow skipped diagnostics instead of silent fallback behavior.
