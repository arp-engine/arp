# Shared conformance workload execution

## Sampled graphics workload /2 (bounded verification complete)

Version 2 extends the existing immutable workload and shared recorder with an explicit ordered `draws` sequence per frame. A draw has exactly `sourceA`, `sourceB`, `target`, `push`, `indexed`, and `expected`. Resource names are `SourceA`, `SourceB`, `PingA`, `PingB`, and `Output`. The first two are immutable authored clears; only PingA/PingB/Output may be targets. Both sampled sources must be distinct and initialized by earlier passes, neither may equal the target, and Output occurs exactly once as the final target and is never sampled. The parser validates these invariants and the caller's explicit draw budget before GPU mutation. Unknown names, missing/extra fields, uninitialized reads, feedback, early/missing Output and budget overflow fail deterministically. Version 1 remains supported by deterministic normalization to one draw; its output oracle remains independent of execution.

The full fixture records SourceA+SourceB -> PingA -> PingB -> PingA -> Output, with SourceB as the second input at every step. Two Clear/Store passes and four graphics passes exercise actual ColorAttachment/ShaderRead transitions, distinct original descriptors, immutable per-draw push snapshots and overwrite-after-read dependencies. Four textures per prepared frame, four descriptor sets (twenty bindings) and all frame metadata are bounded cold allocations. The ordered FrameGraph target catalog contains each exact L2 color/depth attachment pair once; revisiting the same pair remains a separate pass with its original load/store, transitions, order and draw. Distinct pairs (including a different depth owner) remain distinct. This fixes duplicate catalog entries at their shared graph producer; the original executor still rejects genuinely ambiguous catalogs. WebGL CPU upload policy explicitly covers both InitializedByteBuffer byte storage and per-byte initialization coverage (2 * 155648 texture bytes, plus bounded buffers/metadata); 512 KiB is authored for this fixture and the original 256 KiB is a required negative, never an automatic retry. No shader, capability or backend lowering is added. Null remains validator-only; Vulkan uses original render-pass/barrier/descriptor payloads; Metal and WebGPU retain their original preparation requirements and require native target validation; WebGL uses its original ordered issuer under explicit Prototype opt-in. Unavailable original preparation fails closed on every backend.

Acceptance requires the quick schema/graph negative test, Null smoke, original Vulkan and browser execution, and independent native replay of every intermediate edge/output and overwrite, full UBO/push bytes and Post-VS matrix values. Caller reports, expected colors, present counters and source hashes cannot mint output authority. Partial captures cannot certify an incomplete chain. This subset does not close P4-14, open the legacy conformance facade, or promote NativeSync, Platform Validated or Production Ready.

## Sampled graphics workload /1 (bounded verification complete)

`ConformanceSampledWorkload/1` specifies three float3/float2/float4 vertices, three exact Uint16 indices, an original Slang source digest, and bounded frames. Every frame explicitly authors physical extent, two opaque linear UNORM8 source clears, expected output, all 128 UBO bytes (row-major matrix, tint, two values and unused), all 32 push bytes, and indexed/non-indexed intent. Unknown/missing fields, multiple documents, nonfinite/unrepresentable floats, invalid indices, nonopaque output or budget overflow reject before GPU mutation. The expected output is an oracle only; execution must never consume it as a texture, clear or upload.

The workload records two distinct Clear/Store source attachments followed by one sampled graphics pass. The third pass consumes the original vertex/index/UBO resources and both source views, original pipeline/descriptor owners, explicit nearest/clamp sampler, viewport/scissor, full push snapshot and either Draw(3) or DrawIndexed(3, Uint16). All image extents are exact. Shader identity and the existing reflected binding ABI must match before recording. This adds no shader and changes no lowering or capability.
