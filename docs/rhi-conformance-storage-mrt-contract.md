# ConformanceStorageMrtWorkload/1

This bounded Prototype workload is immutable YAML intent above RHI. One original compute dispatch reads an original 48-byte read-only storage buffer and fills a write-only RGBA16F texture. A graphics draw reads that same buffer and samples the compute result by exact texel load, writing two ordered RGBA8 attachments. The second attachment averages the second input float4 and storage texel; the first reads the first input float4. All three independent outputs are checked. Each frame declares physical extent, twelve input floats, two independent expected RGBA8 colors and an independent expected storage float4. Expected values never enter preparation or execution. Every output covers the full declared extent. Frame resources are cold-prepared, quota-bound and retained by the graph after recorder destruction; the caller must drain original execution before resize/retirement.

Admission requires graphics, compute and compute-dispatch, storage-buffer binding, storage-texture binding and the format-specific RGBA16F storage capability, then original compute and graphics pipeline/layout validation for the two color targets and exact reflected descriptor ABI. No backend name grants a capability. Missing capability rejects before resource creation. Required transient aliasing rejects when capability is false; even a true bit cannot authorize this recorder, which has no native alias execution payload. No independent allocations are presented as equivalent aliasing. No production factory, NativeSync or conformance readiness is granted.

| Backend | Approved conclusion |
|---|---|
| Null | Validator-only Equivalent when the published validator capabilities and pipeline validate; never output/native proof |
| Vulkan | Native only through original pipeline/descriptor/command payload and original compute/graphics and format gates; real execution and all three outputs require native replay |
| Metal | Native only when original compute/graphics, storage/format capabilities and pipeline/resource gates accept; otherwise Degraded (capability false) or DiagnosticFailure at the original gate. Target Apple execution remains unvalidated |
| WebGPU | Native only when original compute/graphics, storage/format capabilities and exact write-only RGBA16F binding layout accept; otherwise Degraded (capability false) or DiagnosticFailure at the original gate. Target browser native execution remains unvalidated |
| WebGL1 | DiagnosticFailure: storage-buffer and storage-texture execution unavailable; no extension, CPU replay or MRT emulation is inferred |

Shader source is Slang only, with explicit row-major offline targets. The procedural vertex shader transmits no matrices. SPIR-V, MSL, WGSL and reflection/publication must be generated and checked. The WGSL storage format/access rewrite uses the existing deterministic registered declaration contract. Two render attachment formats are explicit; storage format/access are explicit in the descriptor layout. Original pipeline validation remains authoritative for execution.

Verification requires strict schema/budget/unknown-field/multiple-document negatives, each missing-capability gate across all five backend identities, alias rejection even with a true bit, Null hidden-window smoke, genuine native smoke and AI-inspected RenderDoc replay. Replay must check original buffer bytes, both actual color output owners, independent storage output owner, actual shader bytes, full output pixels and three authored frames. Altered oracle, input bytes, output binding or incomplete coverage must reject. RenderDoc is independent validation tooling, never an RHI issuer or a substitute for sealed original output admission. This batch cannot close full P4-14 or claim Platform Validated/Production Ready.

The shared PipelineValidationReportBuilder projects the complete ordered colorFormats, depth format and unsupported-state result from the L2 validated state. Null and ordinary Vulkan consume this existing builder; WebGPU already consumes it. Metal and WebGL retain their existing complete projections. This is metadata fidelity, never native capability or execution authority. Copying a dynamic format list is cold, allocator-bound work and may throw; the helper must not promise noexcept. Both two-target native smoke paths guard the report against truncation.

The first native replay exposed exact-half UNORM ambiguity: input 0.5 produced byte 127 on this Vulkan device, while the fixture expected 128. The retained failed capture is not relabeled. Final inputs deliberately avoid n+0.5 after UNORM scaling; all storage values are exactly representable in binary16, and every RGBA8 channel has an unambiguous nearest integer. No pixel tolerance or observed-output oracle rewrite is used.
