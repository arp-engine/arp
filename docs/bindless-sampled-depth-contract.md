## Compiler/package ABI

The optional `sampledDepthContractVersion: 1` extends BindlessCross/1. A sampled
table explicitly declares `depthTexture: true` and `dimension: Texture2D` with
TextureShape/1. Its Slang declaration is `DepthTexture2D`, never a color texture
reinterpreted by a name heuristic. The operation ABI is scalar float load,
uint2 base-extent query, and scalar float sampleLevel with an explicit
`ArpBindlessDepthMip { uint value; }` and
independent non-comparison sampler. Texture and sampler indices retain the
existing immutable metadata, active-prefix and fault-latch checks. Integer mip
and load coordinates are checked against actual resource dimensions before
access; failure returns zero and latches fault without sampling.

Fractional LOD, implicit/gradient/compare sampling, depth arrays, multisampling,
storage depth and other dimensions are outside version 1 and reject. A caller
must explicitly construct the integer mip type; a raw float argument fails
Slang type checking instead of silently narrowing to uint. Converting a fractional application LOD is not an
equivalent lowering. This does not change the existing color sampling ABI.

| Backend | Compiler mapping | Execution in this increment |

| Vulkan | Slang DepthTexture2D, SPIR-V Depth=1, float32 sampled 2D | Existing depth Root refusal remains |

| WebGPU | Scalar texture_depth_2d, generated bounded switch | Explicit public Compute execution5 only; general depth refusal remains |

Slang emits an f32 level even for DepthTexture2D's integer-mip helper. The
offline WGSL lowering converts only explicitly declared depth bindings' level
argument to i32. The generated uint level has already passed textureNumLevels:
a uint-sized texture extent has at most 32 mips, so this conversion is exact.
It neither clamps nor fixes the level, and color sampleLevel is untouched.
No handwritten target shader replaces Slang output. SPIR-V, MSL, WGSL and
ordinary reflection must agree on depth semantics before atomic publication.

The runtime package loader preserves depthTexture in the physical layout and
checks it against active ordinary reflection and the SPIR-V image declaration.
Extension versions and physical metadata must match the sealed lowering YAML;
re-hashing an inconsistent package does not authorize it. Required tests include
schema refusal, real cross-target compilation, re-sealed depth/color and binary
shape mismatches, and a browser compilation smoke. Compiler evidence is not
public GPU execution evidence. The next gate reuses original depth clear/store
producers and control2 cells through the canonical inventory/journal.

The next descriptor closure must cover every cell visible through the actual
view. ContentRangeExpectation observes a uniform value across its range; mips
cleared by separate original operations legitimately have different content
generations. Therefore a whole-view expectation cannot replace the bounded set
of authentic per-cell expectations. Capture all cells with their issued stamps,
retain their parent/view and budget owners, and reject missing, pending, stale
or uninitialized cells. Reuse the original range geometry and canonical owner
