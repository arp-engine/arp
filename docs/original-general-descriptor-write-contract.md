Explicit /2 continuation is defined in original-general-finite-binding-contract.md.
It adds finite buffer composition and distinct creation identity while preserving
the /1 language described below. Its native acceptance is pending; it does not
extend existing command/completion/public authorization.

GeneralWrite1 independently opts into publication of one complete scalar
descriptor set through the existing candidate transaction. It covers uniform,
read-only/writable storage buffers, sampled/storage texture views and samplers.
Tables, arrays, dynamic offsets, finite buffer ranges, push mappings, physical
substitution and mixed physical groups remain refused. Binding footprint,
registration generation, original resource/device and accepted pipeline ABI are
validated before native creation and again before atomic publication.

The existing candidate slot, three independent CPU quotas, callback manager,
three genuine error scopes, lifecycle and final revision gate remain the sole
transaction. An opaque request alternative preserves the shared state variant's
size/alignment. It retains individual canonical dependencies plus frozen original
native observations, not the mutable Sources inventory. Buffers retain backing,
allocation and write seal; views retain parent backing/allocation; sampler handles
and device identity remain frozen. Allocation accounting uses core's existing
SharedAllocationProjection, deduplicating exact allocation owners and refusing
inconsistent aliases or authored byte-budget overflow.

Owner bounds reserve the existing fixed custody, the opaque general owner and,
per binding, the largest complete canonical view-parent closure, up to three
metadata quotas, three observation slots and a published binding payload.
The request explicitly bounds binding count, owner slots, all three CPU byte
domains, callback count and retained allocation bytes. There is no production
quota default or automatic budget increase.

Every logical binding and its physical mapping must be supplied exactly once.
The candidate cannot publish before authentic scopes drain successfully. Finish
revalidates immutable originals and native identities, then swaps the complete
writes/payload without allocation and advances the L2 revision once. Failure
preserves the accepted group/revision; cancellation releases only after genuine
callback drain. Pending candidates reject ordinary writes and Source observations.
Committed general groups refuse ordinary command bypass and old finite/whole
identity profiles. Identity version3/GeneralWrite1 checks creation metadata only.
Native closure, freeze/payload, initialized contents, recording, submission and
actual completion still need their original contracts and execution evidence.
