# Canonical ordinary Graphics color native correspondence

Status: implementation in progress; no recording or execution acceptance.

Closure17 is an independent, explicitly opted-in cold correspondence profile.
It consumes authentic Root2, its selected prepared Graphics binding and the
same canonical inventory. Its primary indexed domain remains buffer-only under
independent Preparation11. Ordinary scalar Vertex/Fragment sampled textures use exact
Publication6/control1 whole-upload Sources and Read18/profile3; samplers remain
independent, non-comparison objects. Accepted images are RGBA8/RGBA16F whole
2D, 2DArray and square six-face Cube views. Dynamic/descriptor arrays, depth,
storage, Compute images, partial views and uncompleted inputs are refused.

The backend-private typed descriptor exporter requires the original Root owner,
exact frozen descriptor Source, successful immutable writes and original
publication Sources. Raw descriptor export remains closed for Publication6.
Physical groups reuse the existing issued-pipeline builder and its actual
mapping, stage limits, resource registry, native device, alias and shape checks.
Every sampled Source and native view/parent/sampler belongs to the same retained
inventory and generation. The closure includes the existing color attachment.
Original admission/registration budgets, native/retained owner ceilings,
resource-entry/attachment ceilings and independent CPU quota remain mandatory;
failure publishes no closure and releases temporary groups/owners.

Closure17 grants no execution capability. Preparation11 stays nonexecuting;
Execution2/Closure4 and all older image profiles retain their original scope.
A subsequent explicit execution contract must consume the same Root, stream,
Content9/profile3, Pending9, journal, real callback completion, fault/readback
and retirement. No replacement executor, CPU state commit or synthetic completion
is permitted.

Verification must cover contract/version/opt-in/refusal decisions on all backends,
real uploaded images in all six format/dimension combinations, exact/one-less
budgets and CPU pressure rollback, forged Root/Source/native owners, stale content,
raw-export refusal, hot validation without allocation, and final quota return.
This correspondence evidence cannot prove shader sampling or scene acceptance.
