Compute Roots, geometry actors and attachment-view budgets refuse this profile.

and transaction, rather than a second registry or resource ownership graph.

The closure validates physical native descriptor resource identity, image view,
original parent allocation, device/runtime, pipeline/layout and descriptor-set
owners. A depth descriptor's published proof must have the exact pointer and
shared control block retained by Root, not merely equivalent observations.
Input3 separately validates canonical view, resource/content generations,
revision, range, access and per-input texel/cell/owner ceilings. Root validation
continues to enforce the original frozen descriptor Source6 generation.

Bounded native/retained-owner projection reuses the existing identity inventory.
Entry, owner and metadata budgets are checked before publishing the result;
failed preparation returns all allocations and preserves the input Root. Cold
metadata allocations use core allocators and a separate quota domain. Hot
revalidation must allocate nothing. Real producer reclear must invalidate the
