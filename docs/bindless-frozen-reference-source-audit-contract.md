## Independent namespace/stage archive extension

### Reference predecessor publication/cohort bridge

The existing FiniteLifecyclePredecessorEvidenceInventory/1 inspector may consume
a FrozenReferenceFiniteStageArchive/1 only after its complete independent replay.
An inputs-only FrozenReferenceNamespaceArchive/1 refuses. The publication reader
and its imported SlangResourceSwitch helper must match the exact module bytes in
the attempt's frozen materialized scripts namespace before reading packages.
Missing or changed reader provenance refuses instead of using a newer live helper.

Reuse the existing authoritative bind_packages operation: read archived YAML
publications and payloads, verify byte-hashed identity, then bind all four package
identity fields on every complete-stage report. Missing publications keep the
inventory ineligible; malformed packages or report substitutions reject. Only
this additional proof may derive per-stage shaderPackagesBound and eligibility
for a selected predecessor projection. The raw stage archive's eligibility flags
remain false; aggregate/public/SDK/platform/production authorization is unchanged.

Existing cohort projection, full case coverage, self-predecessor refusal and
final semantic-profile/package-identity comparison also apply to this source.
A reference cohort copies its stage's complete closure and the exact additional
reader/inspection tools needed for a fresh independent Python replay. Original
source labels, package fields and reports are preserved; no missing cohort case
is manufactured, and a final run cannot become its own predecessor. Legacy
stage/post-suppression archive contracts retain their existing validation paths.

`FrozenReferenceNamespaceArchive/1` preserves a proven input namespace while its
native matrix is still running. It copies the attempt's immutable input files,
input/preflight/registration controls, the original reference copies and the
exact inspection tools. It explicitly has nativeAcceptanceInspected=false and
does not copy a live attempt.json or partial native reports as complete evidence.
Original source labels and command tokens remain unchanged. The archived file
layout, hashes, one-to-one copy proof and exact registrations are independently
replayed using archived files alone; original live files cannot fill a gap.

`FrozenReferenceFiniteStageArchive/1` additionally requires successful canonical
inspection of the complete original reference attempt before creation. It copies
the complete acceptance/attempt, every report, driver log and browser log.
Independent replay reuses the same canonical inspector with only the proven
logical materialized ROOT; no native input, report or semantic profile is rewritten.
The archive must contain exactly the declared closure, including its own tools.
Missing/duplicate/escaped copies, changed inputs or tools, incomplete coverage,
forged root/commands, bool coercion and promoted public/aggregate gates reject.

An inputs-only archive never becomes a stage archive by adding reports or
changing a boolean. A complete-stage archive's semantic profiles must equal
independent inspection of its copied reports. Outputs cannot overlap any input
owner and use exclusive creation. Failed creation/replay candidates are retained.
These archives preserve selected evidence only; shader-publication binding,
cohort/final comparison and transitive SDK provenance remain separate. They do
not publish eligibleForAggregatePredecessor or any GPU capability on any backend.
Synthetic complete-stage unit fixtures remain explicitly non-native evidence.

This contract defines CPU evidence inspection, not a GPU command, capability,
lowering mode or native authentication mechanism. It complements the existing
FrozenReferenceFinitePreflight/1 and FiniteLifecycleAcceptance/1 contracts.
All public bindless, aggregate, NativeSync, Graphics, WOCC, platform and production
gates remain false on Null, Vulkan, Metal and WebGPU. Null evidence is validator
evidence only; none of these backends gains execution permission from this tool.

The immutable original reference, materialized namespace and independent attempt
are three distinct owners. Original source paths may be under the original engine
root, including the archived reference itself. Attempt and materialized paths
must not overlap those owners. A missing or changed copy never uses a live engine
source as a substitute.

## Mapping invariants

- Read the attempt's frozen original-input manifest, original registration and
  reference-materialization manifest. Bind their recorded source paths to the
  explicitly supplied reference and materialized directories.
- Verify original archived bytes, materialized bytes and the attempt's frozen
  copy of each materialized input have identical size/hash. Require a one-to-one
  source/path correspondence under the declared source root; reject missing,
  duplicate, escaped or forged sources and copies.
- Require the canonical six source inputs under the materialized source root.
  A queried name or arbitrary new root cannot satisfy this requirement without
  the complete copy proof.
- Match the inspector's actual canonical workflow/validator module files to
  their already frozen attempt copies. Do not edit these modules while the
  original native attempt is running.
- Reuse FrozenReferenceFiniteAttempt.relocate to recompute every selected
  registration. Only driver, runner and output positions relocate. Browser,
  selectors, features and deadlines remain exact. Preserve every failed attempt.
- Preserve strict boolean/type checks and all closed gates. Mapping preflight
  does not inspect incomplete native results or publish a complete stage.

`FrozenReferenceSourceRootMapping/1` records complete=false,
nativeAcceptanceInspected=false and sourceRootMappingVerified=true only after
the above proof. It records selected-input provenance, not transitive SDK
provenance or eligibility as an aggregate predecessor.

## Complete-stage inspection

Only a complete FrozenReferenceFiniteAttempt's acceptance may enter inspection.
The canonical inspect_snapshot function is reused with a private copied global
namespace whose required-source ROOT is the proven materialized directory.
The original module's ROOT, all validators, the manifest, the payload and native
execution remain unchanged. No report fields, native progress or resource
semantics are rewritten. The canonical inspector still checks exact complete
coverage, command identity, report hashes, driver/report equality, original native
markers, retirement and numerical output where required by each selected case.

`FrozenReferenceFiniteStageInspection/1` records only that this strict inspection
completed. It is deliberately distinct from FiniteLifecycleStageAudit/1: it is
not an independently copied stage/cohort archive. Native acceptance inspection,
shader publication/cohort binding, final 204 terminal + 6 numerical acceptance,
SDK provenance and public authorization are separate gates.

The tool detects changes during inspection in original copies, materialized
copies, attempt inputs, loaded validators, registration and acceptance manifest.
Output reports use exclusive creation, so failures or prior observations are
never overwritten. Synthetic unit fixtures are explicitly not native evidence.
