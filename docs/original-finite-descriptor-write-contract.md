This is the f3b2 scoped write-admission Prototype contract; public general writes, Request2,
ordinary finite emission, Source/Inputs/state and NativeSync remain closed.

The existing GpuDevice admits a complete scalar-buffer descriptor set transaction
against one genuine accepted original Compute/RenderPipeline, one original
DescriptorSet and its actual retained original arena. All declarations in that
set are replaced atomically. The caller supplies one original buffer lease,
authored version2 finite write and frozen dynamic displacement per binding,
strictly in binding-number order. This stage selects diagnosed runtime-length
original publications. A binding need not contain a length operation (compute
output bindings do not); its complete original target memory still proves the
declaration minimum/runtime member. A length diagnostic continues to require a
matching operation. Ordinary, uniform-only/non-runtime-profile, array/table,
texture/sampler, mixed/compact logical sets and push groups reject explicitly.
This is a capability-false unsupported profile, not inferred compatibility.

Request/1 requires explicit Prototype opt-in, bounded binding and retained-owner
slot ceilings, exactly the existing three error-scope participants and three
independent CPU quotas for metadata/native payload/callback userdata. No new
canonical owner/root/seal/journal/Source family or native issuer is introduced.
The existing native descriptor group retains private transaction state and real
callbacks retain that same payload until every pop promise returns. Original
pipeline/buffer owners stay in that private state. The logical device is observed
through its existing lifetime ticket; validate it before dereferencing a borrowed
device pointer. Retire/drop/loss is serialized with validation and invalidates it.

Preparation verifies exact device registry, original arena parent/epoch, current
descriptor allocation, available revision, complete original accepted pipeline
control block/creation/layout/package, exact set/layout and scalar stages, genuine
lease/usage/ID/generation, independently aligned base/dynamic, unchanged size,
target minimum/native maximum and static/effective extent. Private frozen limits
are consumed; no hot limits getter, filesystem IO or allocation is allowed.
Ranges are distinct from access coverage. Shader footprint/state authority stays
with f4. Supplied quota domains must be independent of each other and all original
pipeline/device/arena/lease quotas, with fixed captured limits checked again.

WebGPU constructs a complete group using the accepted pipeline's own native bind
group layout. Physical bindings/group come from original target metadata. Entries
carry static base and unchanged finite size; dynamic displacement is kept in
ascending native dynamic-binding order and is applied once by future canonical
emission. Do not manufacture a new layout from logical binding numbers. Native
device and native buffer extents must match the accepted original chain.

Every CPU allocation and callback ticket is cold and quota-bounded before native
scope push. Scope failures, missing methods, bad allocation, pending validation,
changed revision, arena reset, quota mutation, foreign/lost identity or caller
drop publish no successful write and do not advance revision. Candidate native
group/payload cannot become a dummy. Error callbacks only join evidence; they do
not mutate DescriptorSet content or issue native command authority.

The existing DescriptorSet final transaction boundary owns explicit finish.
Begin means Pending only, never a committed successful write. Ordinary write is
blocked while a candidate exists and while committed finite content is active.
Finish revalidates originals, old revision/epoch, budget and every native scope;
then swaps prebuilt vectors/group without allocation and advances revision once.
Ready/failed candidate cancellation releases it without changing old content;
pending cancellation must wait for callbacks before retry, without blocking.
The existing successful-write observations include authored ranges verbatim.

Source/1 and /2 must explicitly reject committed finite writes until f4 versions
their full shader-relative access and positional/state composition. Diagnostic

Backend-private probes may observe the exact committed native group under retained
original owners and completed scopes, without issuing a production command proof.
