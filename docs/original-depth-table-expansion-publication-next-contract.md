## Original geometry positional binding / Inputs5

Inputs5 adds explicitly bounded vertex/index binding records to the existing
OriginalCommandInputs descriptor sequence. Each record names the exact command,
adopted buffer Source, current accepted Graphics pipeline Source, original
pipeline-bind ordinal, render-pass begin and both registration generations.
The same original Usage reference must name that buffer; equal layouts or a
second pipeline cannot substitute for either owner. Missing/reordered records,
wrong scopes, stale pipeline epochs, invalid formats/slots/ranges and exhausted
authored binding ceilings reject before allocation. Inputs1-4 do not accept the
new positional geometry profile. No extra graph, resource Source variant, replay
inventory or native handle is introduced.

Vertex shape is derived from the same retained original pipeline definition,
using VertexInputConsumptionContract's reusable allocation-free stream shape
inspection; it never cold-constructs a second vertex contract while validating.
Index shape reuses the existing known16/32 width mapping. The existing original
Sources/Usage still retain objects and validate lifetime/registration; scalar
binding fields and shape checks alone prove neither initialization nor fetch.
This selected positional profile requires binding after the current Graphics
pipeline in the same render scope. It does not change the general L2 command
ordering contract or certify other ordering profiles.
