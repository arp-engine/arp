arp 引擎使用教程

面向「数据驱动 + 组件化」的 C++17 引擎与渲染框架教程。章节结合当前 src/ 实现和仓库示例，介绍渲染管线、GameObject+Component、动画、粒子、UI、资源、反射、网络、Slang Shader、预制体、资产导入、程序化生成与 ArpScript。

本教程用于介绍系统结构与关键工作流。精确 API、当前支持范围和验证等级以对应源码、contract tests、README 及能力矩阵为准；章节未必覆盖每次接口演进。

引擎与项目的关系

引擎源码位于仓库根目录的 src/。示例与游戏位于 examples/；例如 examples/survivors 展示 Windows/Vulkan 原生运行路径，examples/build_a_queen 还包含显式 opt-in 的 WebGL1 Prototype 示例。示例的存在不代表所有后端或平台都已达到相同验证等级。

章节中的代码和术语以当前引擎源码及对应合约为准。具体系统的验证状态会随后端、平台和功能范围不同而变化；不要把单个示例的通过结果外推为整套引擎的就绪声明。

构建与运行

Windows 本地工作流使用 CMake、Ninja、MinGW-w64、Python、Vulkan SDK 与 Slang。仓库构建入口是 scripts/build.py；preset、构建目标和其他平台要求以 README 与平台构建矩阵为准。

# 本地（MinGW）一键构建 + 着色器
python scripts/build.py --preset win-vulkan-debug configure
python scripts/build.py --preset win-vulkan-debug engine

# 构建 shader 产物与游戏目标
python scripts/build.py --preset win-vulkan-debug shaders
python scripts/build.py --preset win-vulkan-debug game survivors

# 运行完整 CTest 集（目标先构建）
cmake --build --preset win-vulkan-debug
ctest --preset win-vulkan-debug

运行 Windows/Vulkan 示例：

# 风格化展示（隐藏窗口，跑 2 帧）
.build\win-vulkan-debug\arp_survivors.exe --hidden --autoplay --fixed-step --frames 120 --mute

# 运行交互游戏
build\win-vulkan-debug\arp_survivors.exe

其他平台与示例：WebGPU preset 构建浏览器目标；Build a Queen 的 WebGL1 实战使用独立脚本和显式 Prototype opt-in。请按 Platform Build Matrix 与 Build a Queen WebGL1 指南操作，不要把 WebGL1 Prototype 与共享四后端 L2 profile 混为一谈。

术语表

GameObject
场景中的对象节点，拥有 id、名称、父子层级、active 状态与 TransformComponent；组件挂载其上。
Component
挂在 GameObject 上的可复用行为/数据单元，含 onUpdate/onLateUpdate 生命周期与 extract() 渲染提取钩子。
RenderQueue
提取阶段产出的「渲染项 + 队列记录」，携带句柄、元数据、世界变换、包围盒与排序键，不含原生顶点拷贝。
FrameGraph
帧级 pass 依赖与资源规划器；compile() 产出 CompiledFrameGraph（顺序、生命周期、barrier、别名、load/store、队列）。
DrawPlan
渲染器拥有的「绘制计划」，含 submesh/材质 push-constant 与 GUI 文本/四边形绘制命令顺序，经 RHI 编码器录制。
RHI
渲染硬件接口 L2 命令与资源语义；Null、Vulkan、Metal、WebGPU 属共享 profile，WebGL1 是独立的有界 Prototype profile。具体能力和证据见能力矩阵。
Backend-neutral
后端中立约束：scene/renderer/render_graph/ui 不得 include 原生图形/平台头或暴露原生句柄。
pmr 分配器
运行时动态容器统一使用 core::pmr（core::makeUnique/makeShared），禁止默认 STL 动态分配进入热路径。
ResourceManager
引擎唯一的运行时资源注册/缓存中心；资源以类型化 ResourceBase 子类接入，经 load/find/findByAlias 与 ResourceHandle<T> 类型化查询，靠内容指纹支持确定性重载。
Slang
arp 的权威着色器源码语言；构建生成 SPIR-V / MSL / WGSL 与 YAML reflection。WebGL1 的 GLSL ES 1.00 工件由显式工具链从 Slang 生成并受 Prototype 合约约束。
Push constant
每帧提交的小块常量（如 view-projection、材质参数）；L2 atomic payload 上限为 256 字节，实际布局和 backend 能力由 reflection、lowering contract 与执行 gate 校验。
Prefab（预制体）
资产侧的可复用模板，描述 GameObject + Component + 子层级；实例进入场景后变为 SceneObject（见 02）。引擎以 PrefabResource 为引用图枢纽，按 UUID 引用同一内部资产包里的模型、蒙皮、骨骼、动画、材质、运行时负载等资源。
内部资源
引擎统一建模的资产单元，由 ResourceManager 与内部资产包（ArpInternalAssetPackage/v1）管理；当前共 21 个类型（见 10），与项目级 ContentAssetResource（06）共用同一套生命周期/句柄/契约模型。
资产导入
DCC 工具导出的磁盘源格式（如 .glb/.fbx/.png/.mat/.slang）经 importer 转成内部资源包；权威扩展名→类型映射见 assetTypeForExtension()（11）。
