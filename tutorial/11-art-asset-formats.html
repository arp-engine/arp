11 资产导入 Contract Complete

arp 引擎是数据驱动 + 后端中立的风格化渲染引擎。美术资产从 DCC 工具（Blender / Unity / Photoshop 等）导出为标准源格式文件，经 importer 转成引擎内部资源包（确定性 envelope + sidecar blob，见 10），再统一由 ResourceManager（见 06）管理。本文给出当前引擎实际支持的全部资产导入：从磁盘扩展名到内部资源类型的完整映射，所有结论均取自引擎源码（src/resource/prefab_asset_resources.cpp 的 assetTypeForExtension、各 importer、src/assets/asset_pipeline.h、src/shader/shader_compiler.h、src/rhi/gpu_common.h）。

「源格式」与「内部格式」是两件事。 引擎运行时不直接加载原始 DCC 文件。DCC 文件是 importer 的输入；importer 产出的是引擎内部资源包（envelope JSON 描述类型/别名/来源，sidecar blob 存确定性字节）。本文同时列出两层——前者决定「美术能导出什么」，后者决定「引擎真正吃什么」。

2. DCC → 引擎的格式管线

任一美术源文件进入管线后，最终都变成统一的内部资源包格式（第 11 节），与它是哪种 DCC 工具导出无关。

3. 模型与网格（Model / Mesh）

  • glTF 2.0：.gltf（JSON + 外置 bin/贴图）与 .glb（二进制单文件）由 glb_static_mesh_importer（静态网格）与 glb_animated_mesh_importer（蒙皮动画网格）消费；glb_importer_common 统一解析节点层级、PBR 材质与 KHR_materials_* 扩展（clearcoat / specular / sheen / transmission / volume / ior / iridescence / emissive_strength）。
  • FBX：.fbx 由 fbx_character_importer（裸 FBX）与 unity_character_importer（Unity 导出的 FBX + .meta）消费，产出内含蒙皮/骨骼/材质/动画集的 AnimatedMeshAsset。
  • 内部目标资源：ModelResource / SkinnedMeshResource / MeshAssetResource（后者在其它工厂注册，见 10）。网格可选 optimizeIndices / generateBounds / prepareMeshlets（见 RuntimeMeshAssetDesc）。

4. 贴图（Texture）

  • 源格式：位图 .png .jpg .jpeg .tga，glTF 内嵌的 .webp（EXT_texture_webp）；.psd 仅作 Unity 资产数据库的输入（被算作 Authoring，不进运行时像素流）。所有位图经 decodeImageToRgba8()（src/assets/image_decoder.cpp）统一解码为 rgba8 像素缓冲（ImageDecodeResult.rgba8）。
  • 内部纹理格式（rhi::TextureFormat，src/rhi/gpu_common.h:61）：Rgba8Unorm、Bgra8Unorm、Rgba16Float、R32Float（单通道 32 位浮点，用于阴影/深度数据）、D32Float、Depth24Stencil8。UI / 粒子 / 材质贴图运行时均要求 Rgba8Unorm。
  • 移动端压缩（MobileTextureCompression，src/assets/asset_pipeline.h:522）：None / Astc / Etc2 / Bc；开启压缩时必须同时指定移动目标，否则打包失败。纹理另支持 generateMips（生成 mipmap）与 srgb（sRGB 色彩空间）选项。

5. 材质（Material）

  • 源格式：Unity .mat（YAML）由 unity_character_importer 解析为 ImportedMaterial（含 baseColorTexture / normalTexture / cullMode / surface / alphaClip 等）；.shadergraph / .shadersubgraph 作为 ShaderGraph 源（ShaderGraphSource）。
  • 内部材质：引擎运行时消费 SceneStylizedPbr JSON（见 01/SDK 文档，支持 baseColorTexture / normalTexture / roughnessMetallicAoTexture 路径 + biomeTintStrength / lightWrap / weatherMaskStrength 等参数），由 MaterialResource / MaterialSetResource 承载。

6. 着色器（Shader）

  • 源格式：.slang 统一着色语言（见 09）。引擎不直接接触 GLSL / HLSL / MSL 原生方言。
  • 编译产物（TargetBackend，src/shader/shader_compiler.h:18）：.spv（SPIR-V，Vulkan）、.metal（Metal Shading Language，macOS/iOS）、.wgsl（WebGPU），外加 .reflection.json（绑定/推送常量反射，供 ShaderReflectionCache 与 ShaderPipelineReflectionValidator 校验）。一个 shader 包项需同时提供这四类产物（见 RuntimeAssetPackagePlan::shaderReferences）。

7. 动画与骨骼（Animation / Skeleton）

  • 动画 clips 可内嵌于 glTF（glb_animated_mesh_importer 提取）或来自 Unity 角色导入；状态机来自 Unity .controller（AnimatorController）被解析为 AnimatorControllerResource（含参数/状态/过渡）。
  • 骨骼绑定以 Avatar（Generic / Humanoid，见 unity_model_importer_meta.cpp 的 animationType）描述，内部资源类型包括 AnimationClipResource / AnimationSetResource / SkeletonResource / AvatarResource。

8. 粒子（Particle）

  • 源格式：Unity 粒子系统导出为 .prefab 或 .asset，由 unity_particle_importer（直接解析 YAML）与 unity_particle_converter（运行时便捷转换）消费。
  • 内部：ParticleEffectResource，记录各 emitter 及其 materialBinding（引用材质/纹理 UUID），与 04 章的运行时粒子系统对接。

9. 序列 / 过场（Sequence）

  • 源格式：Unity Timeline 的 .playable，映射为 SequenceResource / SequenceBindingSetResource。

10. 创作源（非运行时）

  • .psd .ai .pdf .svg 被 assetTypeForExtension() 归为 Authoring。它们不进入运行时像素流，仅作为管线输入 / 美术审计资产（AuthoringAssetResource）——典型的「源文件，不是引擎资源」。

11. 内部运行时包格式（统一落点）

无论上述哪种源格式，importer 产出的都是同一种内部资源包：一个确定性 envelope（JSON，含 type / name / alias + 每个 entry 的来源与确定性缓存键）加一个 sidecar blob（确定性字节，带内容哈希）。这正是 10 章讲的内部资源模型，也是 06 章 ResourceManager 实际加载的对象。换句话说——

美术关心的「格式」是磁盘扩展名（第 1 节矩阵左列）；引擎关心的「格式」是内部资源包（envelope + blob）。中间由 importer 隔离，上游 DCC 工具怎么变，下游运行时契约不变。

12. 快速参考清单

  1. 导模型优先用 .glb（单文件、内嵌贴图）；需要外部引用或调试用 .gltf。
  2. 贴图统一走 decodeImageToRgba8 → Rgba8Unorm；移动端务必选 Astc/Etc2/Bc 并开 generateMips。
  3. 材质交给 Unity .mat 或引擎 SceneStylizedPbr JSON；不要手写原生 PBR 绑定。
  4. 着色器只写 .slang，三后端产物（.spv/.metal/.wgsl + .reflection.json）由构建脚本生成（见 09）。
  5. 动画/粒子尽可能复用在 Unity 内已验证的 .controller / .prefab，让 importer 处理语义降级。
  6. 不要把 .psd/.ai/.svg 当运行时资产——它们是 Authoring，只参与管线。
